# Подпроект для Nginx
На этом тестовом проекте я изучаю Nginx и разбираюсь во всех его функциях и возможностях.

## Как запустить?
1. Установите Django версии 5.1.
2. В терминале выполните команду `python manage.py collectstatic` в директории _web_.
3. Запустите проект с помощью команды `docker-compose up` в корне проекта.

## Использование:
1. Вы можете перейти по следующим ссылкам:
    1. [http://localhost/](http://localhost/) - Главная страница.
    2. [http://localhost/otherhtml/smail.html](http://localhost/otherhtml/smail.html) - Просто прикол.
    3. [http://localhost/api/time/](http://localhost/api/time/) - Узнать текущее время и дату.
    4. [http://localhost/admin/](http://localhost/admin/) - Админ-панель.

2. Вы можете исследовать директории проекта:
    1. **nginx** - Папка с конфигурациями веб-сервера.
    2. **web** - Папка с конфигурациями Django-сервера.
